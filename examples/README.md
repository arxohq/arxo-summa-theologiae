# Reader examples

Run a directory with `law eval examples/<name>`. Each has the full native request, canonical case/query, and saved canonical result. The adjacent index records its original fixture and expected outcome. No evaluation logic is implemented in the examples.

The 15 moral questions come from six original .lawcase inputs. Five additional inputs come from original .lawtest fixtures: law definition, q. 90 a. 1 argument, natural law, and a guarded theological head with its absent-guard companion. Definition evaluation can also contain a necessity-constraint result; the complete document is preserved.

Inspect with `law inspect examples/<name>/result.json summary`. Negative adjudication, absence and normative positions remain distinct. These fictional examples do not assess a real dispute or prove a theological proposition independently of the model's admitted premises.
