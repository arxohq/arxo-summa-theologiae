# Summa reconstruction: I–II, question 90, article 1

This experimental article-local model reconstructs argument paths from immutable `source.txt`, pinned by `source-pin.json`. It runs against the existing `law.core/0.2` runtime and makes no core or published-package changes.

Source-attested philosophical principles are explicit premises, not independently verified truths. Concrete case inputs trigger named intermediate relations and rules annotated with the source article ID. The model does not assert protected conclusions directly; missing information remains unknown.

`reconstruction.json` inventories the objections, sed contra, respondeo, replies, premises, and obligations. Each implemented branch has a positive scenario and an explicit premise-removal scenario. Runtime truth for a finite fixture would not establish the philosophical assumptions or full article. Obligations remain unverified or conditional, and `fullArticleVerified` is false.

The selected CLI test summary does not retain `skippedRules`; the argumentation class alone is not a skipped-rule audit.
